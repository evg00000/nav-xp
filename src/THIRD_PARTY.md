# Third-party code

`dr_mp3.h` and `dr_flac.h` are single-file decoders from **dr_libs** by David Reid
(https://github.com/mackron/dr_libs), dual-licensed public domain (Unlicense) or MIT-0.
`dr_mp3.h` is based on minimp3 (CC0). The full license statements are at the end of each header.
The files are included unmodified, only so the project builds out of the box.
