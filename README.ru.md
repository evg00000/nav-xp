# nav-xp

Маленький нативный Win32-клиент для серверов [Navidrome](https://www.navidrome.org/) / Subsonic.
Работает на **Windows XP SP2 (32 бит)** на старых процессорах с SSE (от Pentium III) и на Windows 11.
Один файл на C, без зависимостей, exe около 130 КБ.

## Возможности

- Библиотека (исполнители / альбомы / треки), плейлисты, избранное, поиск
- Воспроизведение начинается во время загрузки файла
- Встроенные декодеры MP3 и FLAC, SSE1-ветка для Pentium III; Opus по желанию (`USE_OPUS`)
- Выбор качества потока в приложении: оригинал или перекодирование на сервере в MP3 / Opus
- Очередь воспроизведения рядом с библиотекой, с выделением играющего трека
- 10-полосный эквалайзер, обложки, панель тегов, лайки
- Несколько серверов, настраиваются прямо в приложении (Файл - Серверы, F2)
- Глобальные мультимедиа-клавиши, трей, русский и английский интерфейс

## Запуск

Файл - Серверы (F2): адрес вида `http://host:4533`, логин, пароль, «Проверить», «Подключиться».
Настройки лежат рядом с exe: `nav-xp.sav` (**пароль хранится открытым текстом**) и необязательный `nav-xp.ini`.

## Сборка

Исходник `src/nav-xp.c`, рядом должны лежать `dr_mp3.h` и `dr_flac.h`. **Файл обязан быть в UTF-8 с BOM и CRLF.**
Visual Studio 2010 Express: пустой проект Win32, Release/Win32, `/arch:SSE`, `/MT`.
